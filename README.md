## 🧠 THE WAY I WORK

```text
                     ┌───────────────┐
                     │   USER NEED   │
                     └───────┬───────┘
                             ↓
                    ┌─────────────────┐
                    │  UNDERSTAND IT  │
                    └────────┬────────┘
                             ↓
             ┌─────────────────────────────┐
             │       TEST THE OBVIOUS      │
             │       TEST THE UNEXPECTED   │
             └──────────────┬──────────────┘
                            ↓
                     🐞 FIND THE CRACK
                            ↓
                     🔧 IMPROVE THE FLOW
                            ↓
                     ✅ VERIFY THE FIX
```

> **Good QA isn't about finding more bugs. It's about understanding the product deeply enough to find the bugs that matter.**
