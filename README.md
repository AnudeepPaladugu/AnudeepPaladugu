## 🔍 HOW I THINK ABOUT TESTING

> **A feature is not finished when it works. It is finished when you understand how it can fail.**

- Invalid input
- Boundary conditions
- Unexpected user behavior
- Reproducibility
- Regression impact
- Automation opportunities
